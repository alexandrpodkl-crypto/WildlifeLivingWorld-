# Wildlife: Living World — Minecraft 1.21.1 Fabric

Большой мод о живой природе: наземные животные, птицы, пресноводные и морские виды, хищники и жертвы, стаи/стада, детёныши, размножение, территории, разные боевые профили и выборочное приручение.

## Сейчас в репозитории

- готовый Fabric 1.21.1 Gradle-проект;
- зафиксированы Minecraft 1.21.1, Yarn 1.21.1+build.3, Fabric Loader 0.16.14, Fabric API 0.116.15+1.21.1 и Loom 1.7.4;
- зарегистрирован первый кастомный вид `brown_bear`;
- природный спавн в лесах, тайге и горах;
- повышенное здоровье/урон;
- прототип trust-based taming через рыбу;
- каталог будущих видов: `docs/species_catalog.json`;
- дизайн всех общих систем: `docs/DESIGN.md`.

## Важное ограничение текущей сборки

В этой среде нет доступа к загрузке Gradle/Minecraft/Fabric артефактов, поэтому итоговый JAR здесь не был собран и прогнан через компилятор. Исходники подготовлены под зафиксированный стек 1.21.1; после открытия проекта Gradle должен скачать зависимости.

## Сборка

Нужен JDK 21. Затем:

```text
gradle wrapper --gradle-version 8.10
gradlew build
```

Готовый JAR появится в `build/libs/`.

## Визуал

У первого прототипа временно используется ванильный renderer белого медведя. Это сделано специально: игровая логика отделена от визуала. Следующий production-этап — отдельные Blockbench-модели, текстуры и анимации для каждого семейства животных.
